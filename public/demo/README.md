# Aset demo

Ilustrasi pakaian pada `src/components/outfit-art.tsx` memakai bentuk vektor generik tanpa logo atau referensi aktor. `style-editorial.webp` dibuat dengan ImageGen untuk landing dan inspirasi pada stylist kosong. Gambar menampilkan tokoh fiktif dan disajikan sebagai aset statis dari repo.

Ilustrasi adalah representasi kategori dan warna 2D, bukan model item spesifik, rekonstruksi screenshot, simulasi ukuran, atau try-on. Identifier serta atribut contoh berada di `src/features/demo/data.ts`; harga contoh tidak dinyatakan sebagai harga produk.
