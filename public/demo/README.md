# Aset demo

Ilustrasi pakaian pada `src/components/outfit-art.tsx` dibuat original untuk repositori StyleFit AI, memakai bentuk vektor generik tanpa foto, logo, atau referensi aktor. Hak pemakaian mengikuti proyek ini. Tidak ada aset stok atau keluaran provider yang diimpor.

Ilustrasi adalah representasi kategori dan warna 2D, bukan model item spesifik, rekonstruksi screenshot, simulasi ukuran, atau try-on. Identifier serta atribut contoh berada di `src/features/demo/data.ts`; harga contoh tidak dinyatakan sebagai harga produk.
