# Aset demo

Ilustrasi pakaian pada `src/components/outfit-art.tsx` memakai bentuk vektor generik. `campus-sunshower.webp` dibuat dengan ImageGen untuk landing dan keadaan kosong di stylist, dengan inspirasi suasana dari [Sunshine Through the Rain](https://www.netflix.com/id-en/title/83112494). Adegan dan tokohnya fiktif. Aset disajikan dari repo. Versi visual sebelumnya tersedia di riwayat Git.

Ilustrasi adalah representasi kategori dan warna 2D, bukan model item spesifik, rekonstruksi screenshot, simulasi ukuran, atau try-on. Identifier serta atribut contoh berada di `src/features/demo/data.ts`; harga contoh tidak dinyatakan sebagai harga produk.
